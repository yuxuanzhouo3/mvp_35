## 4. 五条信赖渠道（总览）

每条：**某类代表池 10–20 人 + rotate**。轻度默认 student；中等 professor；高级院士；顶级诺奖 / 图灵。

1. **创业圈信息** — 大S、UCB、哈耶普斯麻、清北复交港  
2. **活跃人才** — 年轻刻苦；代码 / 销售 / 人事  
3. **资金渠道** — 风投 / 大赛 / 政府资金  
4. **市场 / 机构** — 刚需频道、TOB、广告、财务律师  
5. **种子用户** — 1→100 活跃扩散

## 5. 渠道 01 · 创业圈

- 挂名创业圈合伙人代表 10–20 + 轮换  
- **CSO 线：** CSO / VP / Staff / Senior / Junior / Intern / Contractor  
- **CTO 线：** CTO / VP / Staff / Senior / Junior / Intern / Contractor  
- 资深梯度：student → professor → 院士 → 诺奖 / 图灵  

**口播：** CSO 偏战略背书，CTO 偏技术权威；池子轮换，避免单点。

## 9. 种子用户扩散

| 规模（国内外分别） | 解法 |
| --- | --- |
| 几十人 | 谷歌上线解决 |
| 几百人 | 企业内用解决 |
| 几千人 | 待解决 / 裂变 |
| 几万 → 千万级 | VC 加速 / 裂变 |

**TU 参照：** MAU:DAU:WAU:PU ≈ 10W:10000:2000:500（对照约 1000 付费意图）  
**口播：** 先几十上线、几百内用；不吹千万注册。
