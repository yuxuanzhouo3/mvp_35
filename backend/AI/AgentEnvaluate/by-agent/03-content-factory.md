# Agent 评测卡 · 3 内容工厂 Bot（Plan → Draft → Critique）

| 项 | 值 |
| --- | --- |
| 产品落点 | B7 Content Factory · `/content/*` |
| 架构 | Planner → Writer → Critic（合规/品牌/退订）；可挂数字人占位 |
| 代码 | 占位 / 待建；供 B1–B5 触达物料 |

---

## 商业 KPI

| 主扛 | 目标 | Agent 贡献方式 |
| --- | --- | --- |
| `OR` | ≥40% | 标题/首屏文案质量 |
| `AR` | ≥8%（间接） | 素材供 Reachout；不直接改线索分 |
| `ActR` | ≥50%（间接） | 报告侧内容说明可增强行动 |

不进账本；不直接改 `quality_score`。

---

## 技术指标

| 代号 | 门槛 | 测法 |
| --- | --- | --- |
| `SchemaOK` | ≥98% | 选题/渠道/正文/CTA/退订声明字段齐全 |
| 合规闸通过率 | 违禁集 100% 拦截 | Critic 拒 → 不可标「可发布」 |
| `DegradeOK` | 100% | 模型失败 → 模板库 |
| `GroundHit` | ≥90%（含产品事实时） | 不得虚构认证/时效/利润数字 |
| `CostTok` | 低于单次触达预算 | 批量选题复用大纲 |

---

## 其他

- 发布仍受人审或显式开关；工厂≠自动群发。
- 多模态数字人失败不影响文本稿可用性。
- 对赌物料若用于 B9，发出消息仍须 `exclude_from_ar`。

---

## 验收用例（最小）

1. Plan 指定 LinkedIn + 退订 → Draft 含退订 → Critic 过。
2. Draft 含违禁承诺 → Critic 拒，状态不可发布。
3. 关模型 → 模板稿可出，标记 `provider=rules`。
4. 稿内不得出现与规则引擎冲突的利润数字（有报告时应引用锁定值或写「见报告」）。
