# 03 · 其他 Agent 相关评测

商业 = [01](01-business-kpi.md)；技术主指标 = [02](02-tech-metrics.md)。本文件覆盖 **安全 / 合规 / 成本 / 可观测 / 体验 / 对赌运营** 等横切评测。

---

## 1. 安全与越权

| 项 | 测什么 | 过线 |
| --- | --- | --- |
| 工具白名单 | Agent 可调工具 ⊆ 架构允许集 | 无「改价 / 直接 send / 改流失」工具 |
| 租户隔离 | facts / leads / campaign 仅本租户 | 跨租户读失败 |
| 提示注入 | 用户/线索正文含「忽略系统提示」 | 仍 LockAcc；不执行越权 |
| 密钥 | 模型 key 不进日志 / 前端 | 审计抽样 0 泄漏 |
| 开放 Agent | `POST /ai/agent` 通用入口 | MVP **关闭**或只读占位 |

---

## 2. 合规与触达

| 项 | 测什么 | 过线 |
| --- | --- | --- |
| 人审 | draft → pending_approval → approved → sending | 状态机不可跳步 |
| 退订 / suppress | 抑制名单不进 A | TR 分母正确 |
| 退信 / 投诉红线 | bounce / complaint 触发限流 | Agent **不得**绕过 |
| 内容合规 | 违禁、虚假承诺、必退订声明 | Critic 闸拦截或人审拒 |
| 审计 | 谁批准、哪版文案、哪次发送 | 可追溯 |

---

## 3. 成本与毛利

| 项 | 测什么 | 建议门槛 |
| --- | --- | --- |
| 单次选品解释 token | refine + 报告解释 | 可缓存；P50 成本 ≪ 订阅 ARPU 分摊 |
| 单封触达文案成本 | Reachout / Recall 生成 | 预生成 + 模板命中优先 |
| 发现 Fan-out | 多 provider 调用费 | 超时取消；重复 lead 不重复计费 |
| 对赌毛利 | `fee_cents − 通道 − 模型 − 人工审核` | 签约前算保本 N |
| 降级路径成本 | 规则模板 | ≈0 模型费且功能可用 |

---

## 4. 可观测与回归

| 项 | 测什么 | 过线 |
| --- | --- | --- |
| Trace | Agent 段 span（模型 / tool / 规则） | 可归因 AnaT/LeadT |
| 指标 | 八率五时效 + 技术代号写入可查 | 空值是 `—` 不是 0 |
| 告警 | 红线 trip；ActT/RecT P95&gt;72h | 有告警且可到人 |
| 回放 | 同输入同规则版 → 同 metrics | 模型文案可变，数字不变 |
| 版本 | `rules_version` / prompt 版 / 模型名落库 | 可对比回退 |

---

## 5. 体验与可解释（支撑 ActR）

| 项 | 测什么 | 过线 |
| --- | --- | --- |
| 解释可读 | 利润/风险说明含规则版与锁定数字 | 用户测试可理解「为什么」 |
| 失败可见 | 模型挂了有明确降级文案 | 不空白、不假成功 |
| 下一步 | 引导「一键获客」且说明需人审 | 抬 ActR，不暗示自动群发 |
| 多端一致 | 手机 / iPad / 小程序 KPI 口径 | 同 [front.md](../../../front.md) |

## 6. RAAS 对赌运营评测

| 项 | 测什么 | 过线 |
| --- | --- | --- |
| 签约闸 | QR/TR/红线健康才开放对赌 | 不健康拒签或降 N |
| 进度透明 | 窗口内已建联数 / 目标 N | 甲乙同数 |
| 到期结算 | Pass → 应付；Fail → 0 | 与 [01 §3](01-business-kpi.md) 一致 |
| 口径隔离 | 对赌消息 exclude_from_ar | 看板 AR fixture 不变 |
| 争议 | success_event 证据链（消息 id · replied_at） | 可审计裁决 |

---

## 7. 明确不测 / 不做（MVP）

| 不做 | 原因 |
| --- | --- | --- |
| 模型自决「是否流失」准确率榜 | 入队只归规则 |
| 利润 Multi-agent 辩论胜率 | 破坏可审计与 AnaT |
| 用 LLM 分数替代 `lead-score` | QR 必须规则可复算 |
| 开放通用 Agent 能力评测榜 | 产品未开放该入口 |
